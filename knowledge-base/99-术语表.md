# 术语表

> 格式：### 中文（英文）+ 释义 + `kp: 相关知识点`。权威定义以仓库 docs/glossary.md 为准，本表为其源码学习向摘要。

### 能力接缝（capability seam）
一个可替换能力的完整三角色：Service Definition（拥有 `ctx.<key>` 与词汇类型的 Cordis Service，抽象类或具体注册类，禁止 TS interface）+ Service Provider + Consumer。三角色齐备才叫 seam；说其中单角色时用其角色名。
kp: kp-023

### scope（作用域）
每 Agent 的注册单元：注册要么 global、要么 scoped（keyed by 一个不透明 scope key，约定 = live Agent 对象）；两层扁平，不向子代理继承。
kp: kp-022

### scope key（作用域键）
scope 的不透明身份，按对象同一性比较；harness 约定 live Agent 即其自身 scope 的 key。
kp: kp-022

### agent context（agent.ctx）
agent 的 scoped context；经它的注册同时决定 scope 可见性与 scope 生命周期；其上的监听者参与该 agent 的 scope 过滤派发。
kp: kp-022

### shadowing（遮蔽）
最具体者赢的名字解析：scoped 工具/段/变量替换同名全局孪生，仅该 scope 可见——per-agent 人格与工具变体机制。
kp: kp-022

### restriction（限制）
`tools.restrict` 过滤 GLOBAL 工具集于一个 scope（跨链求交）；被滤掉的工具从提示与执行两个面同时消失，与不存在不可区分。
kp: kp-022

### setup window（创建窗口）
创建事务中"scope 与 agent 对象已存在、agent/session 未发布"的窗口；creator 在此组合 agent 的 scoped 世界；setup 只注册、不驱动。
kp: kp-009

### lineage（世系）
父子事实以数据表达（`parentSession`、durable `delegationDepth`、runtime `subagentDepth`）；永不影响可见性。
kp: kp-030

### turn（回合）
一次"排水被接纳输入"的会话过程：模型与其工具停止或终端策略介入后结束；`turn/start … turn/end`。
kp: kp-010

### step（步）
一次模型请求 + 它引发的工具执行；一个 turn 含零或多于零个 step。
kp: kp-010

### round（轮）
包含 turn 的外层策略迭代（goal round / Ralph attempt）；轮计数属于策略，不计会话内每个 turn。
kp: kp-030

### goal（目标）
附着于既有会话的持久完成目标：revision 化的 active/paused/blocked/complete 相位 + goal round 上限；是状态不是调度器。
kp: kp-030

### goal round（目标轮）
为当前目标接纳的一个延续循环；同一会话的无关人工回合不消耗其上限。
kp: kp-030

### goal activation（目标激活）
进程内的续跑授权（armed/disarmed）；刻意不持久化——resume/fork 必须人工重新授权。
kp: kp-030

### Ralph loop（Ralph 循环）
一个前台 fresh-agent 工作流运行：由 workflow 与 subagent 原语组合的模型侧工具策略；每轮 fresh 子会话，共享 workspace + 有界 handoff 传递跨轮状态。
kp: kp-030

### Ralph handoff（Ralph 交接单）
一轮到下一轮的规范化有界结构化报告：status/summary/evidence/next steps/blocker；补充共享 workspace 而非取代它作为权威。
kp: kp-030

### human command（人类命令）
斜杠前缀、由人类界面经 `ctx.commands` 解释执行的指令；不成为模型消息。区别于模型工具与 shell 命令。
kp: kp-031

### profile（组合配方）
命名组合：列出叠加的 bundle、树外插件与用户 `cordis.patch.yml`；出厂 web/headless/sdk/sdk-minimal/acp。
kp: kp-003

### bundle（发行束）
Cordis 配置行 + 代码的发行格式；在包 `package.json` 的 `dsh.bundle` 字段声明。
kp: kp-008

### patch（补丁行）
以 id 为目标的整块替换 / 停用 / insert 三种行操作；层叠顺序 bundle → profile → home → `--patch`。
kp: kp-008

### surface（表面）
模型可见的日志节点集合；替换以 `surfaceOp:'replace'` + `sourceEventSeqs` 表达，历史物理上只追加。
kp: kp-016

### session projection（会话投影）
`dsh-session-projection` 注册的纯 fold 单元：增量折叠提交事件，`stateOf()` 读类型化状态、`snapshot()` 出裁剪客户端视图。
kp: kp-018

### model-visible means logged（模型可见即已记日志）
运行时不变量：任何进入模型请求的内容必须可从会话日志重建；新增模型可见输入必须新增 session 事件。
kp: kp-016

### waterfall（水瀑）
around 中间件式事件派发：监听器收 `(args, next)`，调 `next()` 传递（可包装）结果，直接返回即短路；返回值权威。
kp: kp-007

### assistant/attempt（尝试结算）
未产生 surface message 的一次模型尝试（失败/重试/取消/流错误）的持久结算；log-only，保留精确流供重放。
kp: kp-014

### PTC（programmatic tool calling）
`run_code` 沙盒程序化工具调用：程序以 async 函数体运行，bindings 为宿主函数命名空间；子调用重入完整工具守卫管线。
kp: kp-026

### approval（审批）
一次性人工审批 seam：`allowed-once|rejected|cancelled|unavailable` 闭集，fail-closed；per-session 策略 ask|never 落会话日志。
kp: kp-026

### 执行世界（execution world）
shell/fs/sandbox/subprocess 共享的同一执行上下文：消费者交精确 argv，换 provider 即整体换血（Bash/PTY/LSP 跟随）。
kp: kp-023
